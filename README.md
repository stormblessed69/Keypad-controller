# 🎛️ Keypad Controller for Home Assistant

Controlador físico basado en un numpad inalámbrico HS6209 para manejar Home Assistant mediante Python, evdev y su API REST.

## ✨ Funciones

- 💡 Control individual de luces
- ☀️ Control de brillo
- 🎨 Temperatura/color
- 💡 Control global
- 🔊 Control del JBL
- 🎵 Spotify mediante Spotcast
- 📺 TV/monitor
- 📽️ Proyector
- 🎬 Escenas futuras

## Hardware

**Numpad:**
